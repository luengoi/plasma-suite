# Plasma Suite

A personal suite of native iOS apps and self-hosted services, built to work together.

## Principles

- **Native experiences:** Swift apps built with Apple frameworks.
- **A shared foundation:** Consistent design, interaction patterns, and reusable modules across apps.
- **Connected where useful:** Services that let apps share data while keeping their purposes distinct.
- **Self-hosted services:** Infrastructure and data under personal control.
- **Intentional dependencies:** Prefer Apple frameworks; add third-party mobile dependencies only when clearly justified.

## Status

Early planning. Apps, services, architecture, and tooling are still taking shape. This monorepo will house the clients, shared modules, and backend services.
